# 游戏调试桥接 v1（待 DLL 编译与实测）

在线调试台新增独立「游戏调试数据 · 中文诊断」区，支持 debug.snapshot v1 JSON 导入、模拟诊断、原始数据对照。导入文件不会声称建立了实时连接，也不会修改原任务模拟或游戏。实时入口仅用于本机服务器，在线页面不直接访问电脑。

## 游戏端

草稿代码在模组 Debugging/DebugExporter.cs。默认关闭。游戏启动前设置环境变量 ROOKIE100_DEBUG_FILE 为可写绝对路径，例如 C:\ONI-Debug\rookie100-debug.json。Steam 启动的游戏需继承该环境变量（重启 Steam 或从设置好变量的环境启动）。拿到游戏 Managed DLL 后编译并验证，不能使用旧 Rookie100.dll 代替。

导出复用已有任务扫描结果和复制人监测，不增加建筑扫描。每秒最多输出一次完整文件，以同目录原子替换写入。换档创建新 sessionId；离开存档输出 disconnected 并清空读数。暂停识别、载入过程、DLC、开局星体暂未绑定；当前只报告已载入，不推测正在运行/暂停。

## 本机实时调试

安装 Python 3，下载调试台源码；运行：

```sh
python bridge/serve.py --snapshot "C:\ONI-Debug\rookie100-debug.json"
```

打开 http://127.0.0.1:4173，点击「连接本机桥接」。服务器仅监听 127.0.0.1，以只读方式提供指定文件，不上传数据，不接受游戏控制指令。若无需实时连接，在在线调试台直接导入同一 JSON 即可。

超过 10 秒无新采样显示过期；会话内拒绝重复/倒序序号；换档替换整份数据。采样时间与电脑时钟相关。任务条件自身时间在 objectivesCapturedAt，暂停时可能保持旧值，不代表实时重判。未知数据为 null，不等于 0。

## 后续 DLL 验证

校对 Harmony 生命周期、原版读数及任务判定接口；验证 DLL 完整编译、载入/离开/换档、暂停、复制人死亡/切星体、写入失败、游戏异常退出、中文原因准确性。再绑定 loading/running/paused 状态。当前版本提供数据链路草稿，不保证实机可用，不发布模组二进制。
