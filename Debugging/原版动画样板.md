# 宿舍原版动画样板

本次先验证宿舍这一个教学场景。入口：安顿宿舍 → 分步教学 → 展开动画；标题为“宿舍：原版动画样板”。

使用游戏的 FullMinionUIPortrait 视觉预制体和 KBatchedAnimController 的 UI 材质，不生成真实复制人、床铺或施工任务。床铺是仅带动画控制器的 UI 节点。动画资源直接从当前游戏读取，无需安装 Kanim Explorer，也不随 Mod 分发游戏图集。

已从当前安装的 ANIM v5 原始素材核对以下动作与帧率（均为 30 fps）：

| 动作 | 原版片段 | 帧数 |
| --- | --- | --- |
| 待机 | idle_default | 41 |
| 平地行走 | floor_floor_1_0_loop | 16 |
| 取料准备 / 收尾 | pickup_pre / pickup_pst | 6 / 12 |
| 放料准备 / 收尾 | place_pre / place_pst | 6 / 12 |
| 原地施工准备 / 循环 / 收尾 | build_in_place_pre / build_in_place_loop / build_in_place_pst | 8 / 19 / 9 |
| 床铺空闲 | bedlg_kanim: off | 3 |

复制人的身体由原版 Accessorizer 与普通复制人人格组合。搬料阶段沿用平地行走并将材料图标跟随右手挂点；当前素材文件未提供独立 carry walk 片段。施工播放原版动作，但完整施工光束和特效尚未接入。房间背景与操作标记仍是现有教学示意。

动画控制器保持 Paused，由教学时间轴采样，避免游戏暂停、速度和重复更新影响演示。面板滚动视口增加原版 UI 动画支持的 stencil Mask。初始化和播放失败会显示“原版动画未加载”并回退示意版，日志包含失败详情。成功初始化日志以 Native bedroom lesson ready 开头。

验证：原始资源中 10 个所需片段存在且帧率、帧数有效；针对游戏 DLL 编译 0 警告、0 错误；67 项逻辑检查通过。实际 Unity 渲染、人物比例、手持物位置、滚动裁剪与反复打开面板仍需游戏内确认，不能用编译与纯逻辑检查替代。
