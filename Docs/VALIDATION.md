## 手工验收

1. 旧存档加载后核对已领取状态；保存、退出、重进再核对。不要点击任务重置。
2. 展开 q01 三个教学区，检查换行、滚动、折叠及重新打开；锁定任务也应能阅读。
3. 从 q04 定位已研究和未研究科技：聚焦目标，但原研究选择与队列不应改变；没有研究站时检查反馈。
4. 对照原生人物面板检查卡路里、膀胱充满百分比和具体疾病；观察吃饭和如厕前后刷新。疾病不等于携带病菌。
5. 点击人物卡片定位；检查重命名、加入/死亡、空星球、切换星球和不同存档。折叠或关闭面板后停止状态读取。
6. q03 缺线、无电、缺藻类、过压、手动禁用、自动化关闭应有不同提示；q01 空洗手盆不应通过基础可用性。
7. q05/q07/q09/q12/q14 不应把建筑计数描述为完整循环、永不过载、高压成功、保鲜或气密验证。

首次打开课程可检查日志 `[Phase4B] Loaded course guides: 14`；研究按钮记录“研究跳转请求”。日志不能代替视觉确认。

## 限制与回滚

本批研究聚焦、头像、UI 排版、运行时性能及旧存档读写尚未实际验证。参考布局不是实测蓝图，新增课程正文暂为中文。schema 未变不能替代旧档兼容测试。q02/q04 仍是阅读任务，其余章节完整自动验收分阶段推进。

测试回退可用已备份的 Phase 4A 包。若回退到原始 v0.5.0（旧 JSON 存档架构），须额外检查进度兼容，不能视作无条件安全。安装前退出游戏、备份模组与存档，保持同一安装位置，只启用一个版本，不删除旧进度 JSON。
